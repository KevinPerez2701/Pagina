# Tarjeta de presentación NFC (GitHub Pages)

Este proyecto es una landing de presentación personal, optimizada para abrirse desde un enlace NFC.

## 1) Personaliza tu información
Edita estos archivos:

- `index.html` (nombre, rol, descripción, enlaces)
- `styles.css` (colores, tipografía, espaciados)
- `assets/avatar.svg` (puedes reemplazarlo por tu foto)

## 2) Sube el proyecto a GitHub
1. Crea un repositorio nuevo (por ejemplo: `pagina-presentacion`).
2. Sube el contenido de esta carpeta al repositorio.

Comandos sugeridos:

```bash
git init
git add .
git commit -m "Landing inicial para tarjeta NFC"
git branch -M main
git remote add origin https://github.com/TU_USUARIO/TU_REPO.git
git push -u origin main
```

## 3) Activa GitHub Pages
1. Ve a tu repositorio en GitHub.
2. Entra en **Settings > Pages**.
3. En **Build and deployment**, selecciona:
   - Source: **Deploy from a branch**
   - Branch: **main** / **(root)**
4. Guarda y espera 1-2 minutos.

Tu sitio quedará en una URL similar a:

`https://TU_USUARIO.github.io/TU_REPO/`

## 4) Graba la URL en la tarjeta NFC
En la app de tu NFC (NFC Tools u otra):

1. Escribe un registro de tipo **URL/URI**.
2. Pega la URL de GitHub Pages.
3. Guarda en la tarjeta.

## Recomendaciones
- Usa una URL corta para mejor experiencia (Bitly o dominio propio).
- Verifica en Android y iPhone que abra correctamente.
- Mantén el contenido breve y con llamadas a acción claras.
